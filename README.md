# chiikawa-village

Claude Code 데스크톱 앱의 대화창 뒤 배경 전체를 치이카와 마을로 꾸미는 mod 입니다. 치이카와, 하치와레, 우사기, 쿠리만쥬, 모몽가, 랏코가 마을을 걸어 다니며 서로 이야기하고, Claude 가 하는 일을 보며 한마디씩 합니다.

- **빛은 시각을 따라갑니다.** 현지 시각에 따라 하늘이 새벽, 낮, 노을, 밤으로 바뀌고, 15분마다 새로 그립니다.
- **그림 속 시계는 실제 시각을 가리킵니다.** 오른쪽 아래 버튼이나 `/village 밤` 같은 명령으로 시간대를 고정해도 시계는 지금 시각대로 갑니다.
- **날씨는 컨텍스트 창을 따라갑니다.** 쓴 비율이 25% 미만이면 맑음, 50% 미만이면 흐림, 70% 미만이면 소나기, 90% 미만이면 폭풍, 그 이상이면 소용돌이입니다. 턴이 끝날 때마다 다시 확인합니다.
- **친구들이 마을을 걸어 다닙니다.** 옆으로 갈 때는 걸음 동작으로, 앞뒤로 갈 때는 앞모습과 뒷모습으로 걷습니다. 우사기는 걷다가 멈춰 서서 폴짝 뜁니다.
- **쉬는 동안에는 서로 이야기합니다.** Claude 가 작업하지 않을 때 20~35초마다 둘이 대화를 나누거나 한 명이 혼잣말을 합니다. 밤이나 비 오는 날에는 그때에 맞는 대사가 섞입니다. 이 대사는 미리 써 둔 것이라 모델을 부르지 않습니다.
- **작업하는 동안에는 일 이야기를 합니다.** Claude 의 생각과 글을 Haiku 가 듣고 하치와레나 다른 친구의 말투로 짧은 한마디를 만듭니다. 한마디는 8초 이상 간격으로 나오고, 가끔 다른 친구가 받아서 대답합니다. 턴이 끝나면 말풍선이 사라집니다.
- **오른쪽 아래 버튼으로 시간대를 바꿉니다.** 누를 때마다 자동 → 새벽 → 낮 → 노을 → 밤 순서로 넘어갑니다. 자동은 실제 시각을 따릅니다.
- **사용량 팻말 아래 잔디에 일거리 게시판과 풀밭이 있습니다.** Claude 가 서브에이전트를 띄우면 게시판에 쪽지가 한 장 꽂히고, 친구 한 명이 풀밭으로 가서 풀을 뽑습니다. 쪽지에는 맡은 친구 얼굴, 일 종류(찾기는 돋보기, 일반 작업은 연필, 검토는 안경), 몇 분째인지가 그려집니다. 기다리는 동안에는 노란 딱지가 붙고, 끝나면 빨간 꽃 도장이 찍히고 친구가 "끝났다!" 하고 돌아갑니다. 실패하거나 멈추면 회색 X 도장이 찍힙니다. 도장 찍힌 쪽지는 조금 뒤 바닥에 떨어졌다가 사라집니다. 쪽지는 네 장까지 꽂히고, 풀밭에는 세 명까지 섭니다.
- **입력창 아래 `일거리 2 ▸ 펼치기` 라벨로 자세한 내용을 봅니다.** 에이전트가 일하는 동안만 나타나며, 누르면 쪽지마다 작업 이름, 지금 쓰는 도구, 도구 기록이 담긴 패널이 열립니다. 패널은 저절로 열리지 않아서 대화창을 밀지 않습니다. 에이전트가 끝나면 알림이 뜹니다.
- **왼쪽 벚나무에 사용량 팻말이 걸려 있습니다.** 5시간 한도(모래시계), 주간 한도(달력), 컨텍스트(말풍선)를 열 칸짜리 게이지와 숫자로 보여 줍니다. 한 칸이 10%이고, 칸 색은 50% 미만이면 민트, 80%까지 살구, 그 위는 연빨강입니다. 한도 줄에는 다시 차는 시각(`~15:40`)과 날짜(`~11/21`)가 작게 붙습니다. 숫자는 그림을 새로 그릴 때 함께 바뀌어서 1분쯤 늦을 수 있습니다.

## 명령

| 명령 | 하는 일 |
| --- | --- |
| `/village on`, `/village off` | 배경을 켜고 끕니다. |
| `/village 새벽` · `낮` · `노을` · `밤` · `자동` | 시간대를 고정합니다. `자동` 은 실제 시각을 따릅니다. |
| `/village weather clear` · `cloudy` · `shower` · `storm` · `swirl` · `auto` | 날씨를 고정합니다. `auto` 는 컨텍스트 사용량을 따릅니다. |
| `/village say 할 말` | 하치와레 말풍선에 띄웁니다. 비우면 지웁니다. |
| `/village glass 0~1`, `blur 0~64`, `tint #1b2233` | 대화창 유리의 불투명도, 흐림 정도, 색을 바꿉니다. |
| `/village button soft` · `chip` · `sticker` | 오른쪽 아래 버튼 모양을 바꿉니다. |
| `/village cast on` · `off` | 캐릭터를 그릴지 정합니다. |
| `/village who 하치와레 우사기 …` · `전부` | 무대에 올릴 캐릭터를 고릅니다. |

명령으로 바꾼 설정은 그 세션에서만 유지됩니다. 새 세션은 기본값(배경 켜짐, 자동, 캐릭터 전부)으로 시작합니다.

명령의 답 끝에는 지금 상태와 함께, 앱이 넘겨 준 사용량 한도 목록이 `한도:` 줄로 나옵니다.

## 알아 둘 점

- 배경은 데스크톱 앱에서만 보입니다. 터미널에는 배경 없이 일거리 라벨과 패널만 나옵니다.
- 작업 중 한마디마다 Haiku 를 한 번 부릅니다. 간격은 최소 8초입니다.
- 그림 한 장이 131,072자 한도 안에 들어가야 해서, 앞으로 20~62초 동안의 움직임을 한 장에 담아 그리고 다 되어 가면 새로 그립니다. 새로 그릴 때와 말풍선이 바뀔 때 배경이 한 번 깜빡입니다.

## 설치

터미널에서 연 Claude Code 세션의 입력창에:

```
/plugin install chiikawa-village --marketplace stlim1025/chiikawa-village
```

`Add marketplace?` 가 나오면 `y` 를 누르고, 설치 범위(scope)를 고릅니다. 맨 위의 user 범위를 Enter 로 고르면 이후 모든 세션에서 켜집니다.

셸에서:

```bash
claude plugin install chiikawa-village --marketplace stlim1025/chiikawa-village
```

데스크톱 앱에서는 `/plugin` 이 동작하지 않습니다. 입력창 옆 **+** → **Plugins** → **Add marketplace** 에 `stlim1025/chiikawa-village` 를 넣은 뒤 **Add plugin** 을 누릅니다. 설치한 뒤에는 새로 연 세션부터 배경이 보입니다.

## 업데이트

새 버전이 올라와도 이미 설치한 PC 에는 저절로 들어가지 않습니다. 이 저장소 같은 제3자 마켓플레이스는 자동 업데이트가 기본으로 꺼져 있기 때문입니다.

셸에서 마켓플레이스 목록을 새로 받은 뒤 mod 를 올리고, 데스크톱 앱을 다시 시작합니다:

```bash
claude plugin marketplace update chiikawa-village
claude plugin update chiikawa-village@chiikawa-village
```
